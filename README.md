# Find Largest of Three Numbers

## Description

This Python program accepts three numbers from the user and determines the largest number using conditional statements.

It also identifies whether all three numbers or two numbers are equal.

## Concepts Used

* Variables
* User Input
* Type Conversion
* Comparison Operators
* Logical Operators
* Conditional Statements
* Functions
* Return Values
* Exception Handling

## Technologies

* Python 3

## How to Run

```bash
python largest_of_three.py
```

## Sample Output

```text
===================================
     LARGEST OF THREE NUMBERS
===================================
Enter first number: 25
Enter second number: 75
Enter third number: 40

Numbers Entered:
First Number  : 25.0
Second Number : 75.0
Third Number  : 40.0

Largest Number: 75.0
```
